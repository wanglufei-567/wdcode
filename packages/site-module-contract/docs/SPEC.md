## 站点模块契约规格

### 一、职责

`@wdcode/site-module-contract` 定义个人站主应用与根级业务模块之间的稳定装配协议

契约只描述模块标识、导航入口、路由和站点公共组件，不包含任何具体业务页面、内容数据或部署逻辑

### 二、依赖边界

- 主应用依赖模块公开入口，并负责装配所有模块
- 业务模块依赖本契约，不依赖主应用内部实现
- 业务模块之间禁止直接依赖
- 契约包不得依赖任一业务模块

详细编码规则以根目录 [`docs/CODING_STANDARD.md`](../../../docs/CODING_STANDARD.md) 为准

### 三、运行边界

模块在构建时注册到同一个 **React** 应用，共享一个 **Router**、一个静态产物和一个部署镜像

站内模块由主应用静态导入，模块代码和样式随主应用入口加载完成，应用启动后的导航切换不跨越动态导入边界

当前契约不提供远程模块发现、独立进程、独立镜像、运行时通信总线或 **Module Federation**
