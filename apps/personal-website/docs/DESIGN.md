## 个人站设计规范

### 一、设计姿态

个人站应当像一份经过整理的技术阅读索引，克制、清晰、安静

首页先用一句中文主张建立个人辨识度，再以三列图文卡片呈现精选文章，所有视觉元素都服务于文章识别和阅读选择

禁止演变为产品导航、营销落地页或内容平台，不增加搜索、评论、订阅、动态推荐、统计数字和转化按钮

### 二、视觉系统

#### 2.1 色彩

使用限制型配色，绿色只承担识别和交互信号，不超过页面视觉面积的 `10%`

```css
--color-page: oklch(0.985 0.004 145);
--color-surface: oklch(1 0 0);
--color-ink: oklch(0.18 0.012 145);
--color-body: oklch(0.38 0.014 145);
--color-muted: oklch(0.48 0.014 145);
--color-line: oklch(0.90 0.010 145);
--color-signal: oklch(0.52 0.105 145);
--color-cover-memory: oklch(0.91 0.045 145);
--color-cover-harness: oklch(0.91 0.040 245);
--color-cover-agent: oklch(0.93 0.045 75);
```

正文与背景必须满足 **WCAG AA**，低优先级文字不能使用接近不可读的浅灰

#### 2.2 字体

- 首页主标题使用 **Noto Serif SC** `600` 字重的最小字符子集，以中文衬线体提供安静、成熟的字形辨识度
- 字体子集只包含当前主标题字符，修改主标题时必须同步更新字体子集
- 字体文件和 **OFL 1.1** 许可证随应用保存
- 正文和界面使用操作系统原生无衬线字体，中文优先 `PingFang SC`、`Noto Sans CJK SC`、`Microsoft YaHei`
- 不下载专有字体，不把等宽字体当作开发者身份装饰
- 等宽字体只用于代码和系统图中的短技术标签
- 首页主标题最大 `72px`，字距不得小于 `-0.04em`
- 正文基础字号 `16px`，行高 `1.8`，正文列宽控制在 `72ch` 内
- 标题使用 `text-wrap: balance`，长段落使用 `text-wrap: pretty`

#### 2.3 空间与几何

- 基础空间单位为 `4px`，主要间距使用 `8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`
- 页面内容最大宽度 `1160px`，桌面边距至少 `32px`，移动端边距 `18px`
- 文章卡片圆角固定 `6px`，不使用超大圆角
- 卡片使用单一细边界，不叠加宽模糊阴影
- 页面不使用渐变文字、玻璃拟态、条纹背景和装饰性数据面板

### 三、核心组件

#### 3.1 顶部栏

- 左侧显示 `WD CODE`，点击回到首页
- 右侧只显示“首页”和“笔记”两个一级入口
- “笔记”保留绿色状态点，表达当前内容定位
- 不扩展复杂导航

#### 3.2 首页身份区

- 桌面端采用不对称双栏，左侧为唯一短标签，右侧为中文主标题和说明
- 移动端退化为单列
- “边界、机制、运行链路”是首页唯一方法锚点
- 说明不把内容范围限定为前端工程，也不直接宣称资历或身份标签
- 说明可以明确点出 **AI Agent** 与 **AI Coding** 作为当前研究主题，但不把它们升级为身份口号
- **AI** 方向和工程经验由说明、文章主题、问题深度与论证方式共同建立
- 身份表达必须由文章和长期工程实践支撑，不使用营销口号或泛化价值判断

#### 3.3 文章卡片

- 桌面端三列，窄屏使用 `auto-fit` 自然降为两列或单列
- 卡片由机制封面、标题、摘要和“阅读文章”链接语义组成
- 封面必须表达文章机制，例如记忆分层、Harness 边界和 Agent 控制循环
- 不使用无意义占位图、日期、阅读时长、标签云和装饰性编号
- 整张卡片可点击，键盘焦点清晰可见

#### 3.4 正文页

- 笔记页使用目录侧栏和单列阅读布局
- 根目录和子目录按 `DebrisRecord` 原始名称展示
- 正文页显示路径面包屑、文件名标题和 Markdown 正文
- 代码块、表格、引用和行内代码必须在移动端保持可读
- 原始 **HTML** 不进入渲染链，未知文章显示明确的不存在页面
- Markdown 内部文章链接进入对应 `/notes/*` 路由，相对图片按当前文章目录读取
- 移动端隐藏一级目录侧栏，通过面包屑和当前目录继续导航

### 四、交互与响应式

- 交互只保留链接颜色、边界和最多 `3px` 的位移反馈
- 动画时长控制在 `160ms` 左右，使用减速曲线
- `prefers-reduced-motion: reduce` 下移除非必要动画
- 所有交互元素支持键盘访问和 `:focus-visible`
- `390px` 宽度不得产生水平页面滚动，正文表格和代码块允许组件内部横向滚动

### 五、内容语气

- 使用具体的工程名词和动作，不使用营销术语
- 标题说明文章讨论什么，摘要说明读者可以理解什么
- 英文技术名词保留原文，中文说明承担主要信息
- 不使用重复标语、感叹号堆叠和制造焦虑的文案

### 六、**AI Coding** 守门规则

- 修改界面前先阅读本文件和 `docs/CODING_STANDARD.md`
- 新增色彩、字号、间距和圆角前优先复用现有令牌
- 不因增加文章数量引入筛选、分页或搜索，除非形成独立需求
- 不把 `DebrisRecord` 原文复制进源码目录或个人站镜像
- 不用第三方组件库替代当前少量语义组件
- 视觉变更必须验证桌面端、移动端、键盘焦点、控制台和生产构建
